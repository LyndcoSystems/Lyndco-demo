# Lyndco Systems interactive demonstration

Public demo: https://demo.lyndcosystems.com/

The feature buttons illustrate possible customer journeys. The interest form sends enquiries to Formspree.

Legacy `/callback/` and `/callback.html` routes redirect to the canonical HelpPoint packages page at https://www.lyndcosystems.com/helppoint/ . This demo no longer hosts a duplicate order form. `/book/` is retired.

Do not commit customer records, private legal drafts or credentials.
